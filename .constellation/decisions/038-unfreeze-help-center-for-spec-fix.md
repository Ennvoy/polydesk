# 038 解凍使用說明以修正完整性缺口

## 背景

出貨 Spec 軸逐項盤點現有使用者入口後，確認定稿的完整使用指南漏掉「總覽／AI 用量」與「AI 產生 commit 訊息」，使 T-003 的完整性驗收無法成立。

## 決定

只解凍 `src/renderer/components/Help/HelpCenter.tsx`，補齊上述兩項說明與搜尋回歸；其餘定稿畫面維持凍結。修正完成後重新凍結該檔並交回原 Spec 軸複審。

## 原因

這是補齊既有功能說明，不改變已核准的 Help Center 版型、資訊架構或視覺方向；以最小解凍範圍消除出貨阻擋。

## 證據

執行端列出「1. 解凍並補齊指南（建議）」與「2. 維持凍結」後，使用者於 2026-08-10 回覆「1」。
