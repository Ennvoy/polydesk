# 048 多 remote 同名分支逐一選擇

## 背景

同一條本地分支可能在多個 remote 上有同名分支，而 remote 名稱本身也可以含斜線；一次刪除全部同名遠端會誤傷備份或其他團隊的 ref。

## 決定

使用者勾選連同刪除遠端後，Polydesk 顯示結構化 remote／branch 清單供逐一複選；預先勾選本地分支目前追蹤的 remote，其他同名遠端不自動勾選。本地分支沒有 upstream 時，清單仍可手動選擇。

## 原因

逐一選擇可以支援一次清理多個明確目標，又不會把「同名」誤當成「都該刪」；預選 upstream 則減少最常見情境的操作步驟。

## 證據

訪談題目：「若多個 remote 都有同名分支，勾選遠端清理後要刪哪一個？」使用者後續授權「全部依照你的建議做完」，因此採用推薦選項 1：顯示清單逐一勾選，並只預選 upstream。當時依據為現行 GitService 已保留結構化 remote 身分，不需要從顯示字串反向拆解。
