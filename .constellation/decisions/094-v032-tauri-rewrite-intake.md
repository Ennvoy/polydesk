# 094 v0.32 需求入口：評估將 Polydesk 改寫為 Tauri 架構

- 背景：v0.31 訪談收尾時，使用者提出下一個大需求——嘗試把 Polydesk 完整改寫成 Tauri 架構。
- 決定：本項**不納入 v0.31 範圍**，維持本輪出貨邊界；v0.31 完成發布後另開一輪 Constellation 訪談處理。本筆僅作需求登記，不構成任何技術決策。
- 原因：Electron 改 Tauri 需將整個 main 程序（PTY／ConPTY、Git、LSP bridge、檔案監看與搜尋、AI 監控、狀態儲存、自動更新、打包發布）由 Node 重寫為 Rust，並重新驗證既有全部安全邊界與真鏈路 E2E，規模為 v0.31 的數倍。與本輪兩個功能混做會同時破壞兩者的可驗證性。
- 證據：使用者原話「等改完之後我還有一個大需求，我想嘗試著把polydesk完整改寫成tauri架構」。當時依據為既有 `MAP.md` 記載之 main 層模組範圍；尚未進行任何 Tauri 可行性查證。

> **版本更正（2026-08-20）**：本筆登記時寫的「v0.32」為當時的預期版號，該版號已由終端機滾輪修正發布使用。Tauri 改寫的實際版號待本輪功能出貨後再定，登記內容不受影響。
