# 115 搬移目標只列已納管工作區，不提供納管捷徑

- 背景：獨立審查指出，決議 113 的典型情境（請 Claude 建立 worktree、Claude 隨即 cd 進去）產生的是**外部 worktree**，而決議 085 已排除自動納管，故該 worktree 在搬移當下並未成為工作區，搬移選單不會列出它。使用者需先經 SCM → worktree 分頁 →「切換到此」→ 確認加入（該動作會切走目前工作區）→ 再切回來，才能執行搬移。
- 決定：**搬移目標只列出已納管的工作區，不提供納管捷徑、不加額外說明文字。** 維持現狀。
- 原因：使用者評估後選擇不為此加工。納管路徑已存在且可用，只是步驟較多；新增「加入並搬過去」的複合操作會把 085 排除的納管邏輯引入搬移功能，擴大範圍。代價為在該典型情境下，使用者需先自行完成納管，搬移選單在此之前不會出現目標，且畫面上不會說明原因。
- 證據：使用者於彈窗選擇「維持現狀，什麼都不加」，題目已完整載明六步操作的代價。
