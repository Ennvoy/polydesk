# 009 分開發布兩項功能

## 背景

本輪原先聚焦 SCM 分支管理，訪談途中另加入 Claude／Codex 對話軸只顯示使用者文字的需求。兩項功能分別涉及 Git 服務與 SCM 介面，以及終端機 transcript／rollout 對應，驗證鏈路彼此獨立。

## 決定

先完成並發布 SCM 分支管理：本地／遠端分組顯示、安全刪除、確認流程與 worktree 防呆。Claude／Codex 使用者文字對話軸延至下一個獨立 Constellation 開發與發布週期；決議 006–008 保留為下一輪已確認需求，不納入本次實作與出貨範圍。

## 原因

分開發布能讓每一版維持單一可驗證目標，避免 Git 遠端操作與 AI 終端機 session 對應兩套高差異風險同時進入同一個版本，也方便分別回歸與回退。

## 證據

訪談詢問兩項功能的交付方式時，使用者選擇分成兩個獨立版本，並再次確認先做第 1 項分支管理。
