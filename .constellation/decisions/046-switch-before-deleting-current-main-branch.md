# 046 刪除主工作樹目前分支前先選擇切換目標

## 背景

主 repository 的目前分支無法直接刪除，而現行 Polydesk 只會停用操作，使用者必須先手動切換分支再回來重做刪除。

## 決定

刪除主工作樹目前分支時，Polydesk 要求使用者先選擇另一條本地分支；工作目錄乾淨時先切換到所選分支，再接續原本的刪除流程。若有未提交變更或沒有可選的其他本地分支，則停止操作並明確說明原因。

## 原因

讓使用者指定下一個工作位置，可以在 Polydesk 內完成整個操作，又不會自動切到非預期分支或為了刪除而丟棄未提交變更。

## 證據

訪談題目：「如果要刪的是主 repository 目前正在使用的分支，Polydesk 要怎麼處理？」使用者選擇選項 1：「讓主人先選另一條本地分支（推薦）」。當時依據為 Git 不允許刪除目前簽出分支，且現行 Polydesk 已有分支切換能力可作為前置步驟。
