# 080 側欄定稿與清理對話框解凍授權

- 背景：側欄頂部功能列已在隔離的本地 Electron 開發版供使用者檢視；T-008 串接遠端清理時，第一階段對話框仍需補上明確 opt-in 行為契約。
- 決定：使用者選擇「1」，核准側欄版位定稿，並授權暫時解凍 `BranchCleanupDialog.tsx` 完成遠端 opt-in 串接；`scm.css` 維持凍結。
- 原因：側欄位置已符合「控制項貼近受控內容」的操作模型；清理對話框的調整屬原定兩階段流程必要接線，不是重畫視覺方向。
- 影響：T-009 可完成正式驗證與凍結；T-008 可修改第一階段元件，完成後若視覺不變可直接重新凍結，若視覺有實質變更則需再次本地互動拍板。
- 證據：使用者在 2026-08-13 回覆「1」，對應提示中的「這版定稿並批准解凍（推薦）」。
