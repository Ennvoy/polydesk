# 006 對話軸只顯示使用者文字

## 背景

終端機左側導覽軸目前會同時出現使用者輸入與模型輸出；長回覆會產生大量刻度，降低快速定位自己提問的價值。Claude 與 Codex 的目前資料路徑不同：Claude 已讀角色化 transcript，Codex 仍使用一般終端機行導覽。

## 決定

Claude 與 Codex 的對話軸都只顯示使用者輸入的文字節點，不顯示模型回覆節點。節點仍可用來定位對應的使用者提問。

## 原因

使用者希望導覽軸作為「我的提問索引」，而不是整段對話的密度縮圖；排除模型輸出能減少雜訊並提高定位效率。

## 證據

使用者原話：「我希望這個對話軸只顯示我的文字就好，模型的文字不用，codex跟claude都是」。當時程式盤點確認 Claude transcript 已保留角色；Codex rollout JSONL 亦有結構化 user message 事件，可避免以畫面文字猜測角色。
