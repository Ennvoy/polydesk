# 005 分支刪除阻擋狀態

## 背景

目前簽出的本地分支與被其他 worktree 簽出的分支無法安全刪除；若直接隱藏操作或等 Git 失敗後才解釋，都會讓可用條件不清楚。

## 決定

這類分支仍顯示刪除選項，但將其停用，並在選單中直接標示「目前分支」或「由 worktree 使用中」等具體原因。

## 原因

保留入口可讓使用者理解功能存在，立即顯示原因則避免多走一次必然失敗的操作流程。

## 證據

訪談題目：「目前正在使用，或已被其他 worktree 使用的本地分支，刪除選項要怎麼呈現？」使用者選擇選項 1：「保留選項但停用，旁邊直接寫原因（推薦）」。當時依據為 Git 與 worktree 的分支互斥限制。
