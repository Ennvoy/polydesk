# UI 設計定稿：本機可執行 Electron 版本

- **Claude Design**：本次執行環境沒有可用的 DesignSync／Claude Design 工具；已先向使用者說明，自行撰寫的版本不等同設計服務探索過的多方向。使用者選擇留在目前環境，由執行端直接撰寫真實畫面 code。
- **設計基底**：沿用 Polydesk 既有 React 元件、theme tokens、按鈕／dialog／標題列與深色介面語言。
- **需求描述**：移除最左固定活動列，把檔案總管、搜尋、原始碼控制及設定整合到工作區標頭；新增首次短導覽、可搜尋完整使用說明與冷啟動等待畫面。
- **方向數量**：一版。依降級路徑先做可執行版本，再由使用者依真 Electron 截圖迭代；沒有以同一判斷的多種寫法冒充多方向探索。
- **使用者選擇**：使用者看過冷啟動畫面、首次導覽、工作區工具列與使用說明四張真 Electron 截圖後，回覆「1」，選擇定稿並繼續完整驗證與出貨。
- **調整紀錄**：沒有要求額外畫面調整；定稿採 7 步真介面導覽、工作區標頭水平工具列、分類＋搜尋的說明中心，以及 250 ms 後才顯示的 420×230 splash。
- **轉譯判斷**：畫面從一開始就直接落在專案元件，沒有 canvas 拉回或格式轉譯；CSS class 沿用 `pd-` 命名與既有 tokens，沒有 Tweaks、假資料或殘留 variant 開關。
