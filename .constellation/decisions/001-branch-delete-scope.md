# 001 分支刪除範圍

> superseded in part by 043：本地未合併分支改為可經二階段確認強制刪除。

## 背景

SCM 分支頁目前只顯示本地分支，且尚無刪除能力；本地分支與遠端伺服器分支的刪除語意及風險不同。

## 決定

第一版同時支援本地與遠端分支刪除，兩者在畫面與確認流程中明確分開。本地分支只提供 Git 安全刪除，不提供強制刪除尚未合併分支。

## 原因

一次補齊完整分支管理能力，同時避免模糊操作誤刪遠端內容；不提供強制刪除可降低未合併 commit 遺失風險。

## 證據

訪談題目：「第一版的刪除範圍要做到哪裡？」使用者選擇選項 1：「本地＋遠端分開刪（推薦）」。當時依據為程式盤點確認後端已分別回傳本地與遠端追蹤分支，但尚無刪除 API 或 UI。
