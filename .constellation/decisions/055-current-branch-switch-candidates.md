# 055 目前分支切換目標必須可立即簽出

## 背景

刪除主工作樹目前分支前需要先切到另一條本地分支，但其他分支也可能正被其他 worktree 使用，無法成為即時切換目標。

## 決定

切換下拉只顯示本地存在、不是待刪目標、未被任一其他 worktree 簽出的分支。送出後 main 端再次驗證候選仍存在且未被佔用；若候選過期或全部其他分支都不可切換，等同沒有可選分支，停止清理並說明原因。

## 原因

預先排除必然 checkout 失敗的分支，可避免清理流程中途又跳到「前往其他 worktree」的矛盾分支，並保持對預檢後外部 Git 變動的 fail-closed。

## 證據

使用者授權「全部依照你的建議做完」。獨立盲點審查指出現行 checkout 遇到已佔用分支會改走跳轉 worktree 流程，與決議 046 的「先切換再接續刪除」不相容。
