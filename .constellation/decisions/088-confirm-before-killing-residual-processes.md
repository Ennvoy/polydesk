# 088 關閉分頁清理殘留前先詢問使用者

- 背景：關閉終端機分頁改為「清得從底」後，會一併終止 AI 退出後留下的孤兒程序（dev server 等）。這些程序在 Polydesk 畫面上不可見，使用者無從得知自己剛才終止了什麼。現行關閉分頁為直接關閉、不詢問。
- 決定：關閉分頁時若偵測到該分頁任內留下的殘留程序，**先列出並詢問使用者是否一併關閉**；沒有殘留時維持現況一點就關、不跳任何視窗。
- 原因：終止使用者可能仍在使用的 dev server 屬不可逆的破壞性行為，且對象在畫面上不可見，事後告知無法挽回。以「只有真的有殘留時才問」換取誤殺零風險，日常無殘留的關閉操作不受影響。
- 證據：使用者於彈窗選擇「有殘屍時先問我一次」，題目為「關分頁改成清得從底之後，它會多殺掉一些現在殺不掉的東西……這個行為要不要變？」。當時依據為本機實測確認孤兒 dev server 於現行 `taskkill /T` 下存活、使用者無從察覺。

> **superseded by 092**：清單範圍已由「僅孤兒」擴大為全部成員。
