# 087 終端機搬家只搬分頁歸屬，不改變 shell 工作目錄

- 背景：`TerminalPanel.tsx` 以 `t.wsId === activeWs.id` 過濾顯示，既有分頁重排在 `TerminalPanel.tsx:257` 明確以 `arr[from].wsId !== arr[to].wsId` 拒絕跨工作區。使用者要的是打開這道限制，讓分頁可挪到另一個工作區的終端機區塊。惟 shell 啟動後 cwd 無法由外部改寫，搬移後 shell 仍在原工作區目錄。
- 決定：本功能**只移動分頁歸屬**（renderer 顯示分組與 main 端 `PtyManager` 的 wsId 一併更新，使關閉舊工作區不再誤殺、重啟後仍在新位置）。**不送 cd、不重開 shell、不詢問**；搬移後目錄仍為舊路徑，由使用者自行決定是否 `cd`。
- 原因：使用者的需求就是分頁的視覺與歸屬位置，不是工作目錄。自動送 cd 需判斷 shell 是否閒置，在 Windows 終端機上無法百分之百可靠，誤判會把該行字打進正在執行的程式（例如 Claude 的對話框）；為未被要求的便利性承擔此風險不划算。
- 證據：使用者原話「我想要搬家的部分是可以把這個終端機分頁換到另一個工作區裡面的終端機區塊」，以及對目錄處理的回答「不用，我只要能移動分頁就好」。當時依據為本機讀碼確認 `TerminalPanel.tsx:257` 的跨工作區封鎖與 `PtyManager` 對 `wsId` 的 `killWorkspace`／`pty:list` 依賴。

> **修訂**：「重啟後仍在新位置」應為「重新載入畫面或切回工作區後仍在新位置」——終端機本來就不跨 Polydesk 重啟保留。
