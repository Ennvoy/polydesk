# 訪談收尾（grill-close）

| 欄位 | 內容 |
|---|---|
| 大小流程 | 大流程：完整涵蓋訪談收斂、UI、設計與實作，直到出貨交付。 |
| 是否需要 UI | 是；沿用 Polydesk 既有介面與架構。 |
| 高風險標記 | 權限／資安高風險：涉及裝置配對、工作區授權及遠端啟動。 |
| 必備模組排除 | 排除多租戶帳號管理模組；此需求不建置為 SaaS。 |
| 一句話任務摘要 | 使用者透過手機私人網路，一鍵在自己的 Polydesk 啟動固定 Claude bypass 能力。 |

## 範圍基準

- 依決議 133 完成端到端流程與 UI，工程預設詳見 [engineering-defaults.md](engineering-defaults.md)。
- 保留每人控制自己的 Polydesk、已授權工作區白名單與電腦端配對批准；不擴大為一般遠端命令執行。
- 對於逾時、未知結果、Tailscale 不可用、權限失效或紀錄容量已滿，一律採 fail-closed，依工程預設指引回報與查詢。
